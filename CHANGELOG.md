# Changelog

All notable changes to this project are documented in this file.

## [0.1.0] - 2026-08-17

### Added

- Render settled `mermaid` fenced blocks in the DeepSeek Harness Web UI.
- Provide independent inline zoom controls for every diagram.
- Open diagrams in a full-viewport workspace with fit, zoom, wheel and drag panning, keyboard shortcuts, and collapsible source.
- Restore the original code block and all plugin-owned DOM changes during Cordis disposal or client-plugin HMR.
- Display controlled parse errors while preserving the original Mermaid source.
